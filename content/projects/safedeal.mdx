## The Problem

Comparing a product across AliExpress, Amazon and eBay means opening each shop one by one, and nothing tells you whether the seller can be trusted. On a phone it is worse: there are no extra tabs or browser extensions to help.

Safe Deal already had a browser extension for desktop. The mobile app had to bring the same verdict to the phone, on the product page itself.

## What I Built

I was a contributor on the Safe Deal mobile app in late 2024. It is an **Expo / React Native** shopping browser: each shop loads inside the app in a **WebView**, and a bar under the page turns green, yellow or red with a verdict on the product you are looking at. My part was mainly the in-app browser, state and data:

- Routed every tapped link through the app, so each product page gets checked. Only http and https requests are allowed.
- Added a **redirect-loop guard**: more than 15 loads of the same URL within 10 seconds stops the page.
- Built the WebView user agent from the device's own, so shops treat it like a normal mobile browser.
- **Injected scripts** that fix the viewport and hide promo banners as the page changes.
- Moved app state from Redux and React Context to **Zustand**, and reworked data fetching with **React Query**.
- Fixed the price history chart, review images and insights loading, and the onboarding tour tooltip.

The app itself has more: a verdict sheet with Insights (shop rating, return policy, delivery time, shipping cost), Reviews (pros, cons and an AI summary of buyer reviews), buyer photos and YouTube reviews, plus price history, a share-into-the-app shortcut and 55 locales. The browser extension and the backend were built by others.

## Key Challenges

**Pages that redirect in loops.** A page that keeps redirecting would freeze the browser, so I count loads per URL in a 10-second window and stop past 15.

**Looking like a normal browser.** Shops behave differently inside a WebView, so the user agent is built from the device's own with the WebView marker removed.

**Keeping the verdict in step with the page.** On each navigation the old verdict resets, and an analysis request goes out only for valid shop and product URLs.

**State in three places.** App and onboarding state moved from Redux and React Context into Zustand stores, while server data stays in React Query.

## Results

Live on [Google Play](https://play.google.com/store/apps/details?id=com.safedeal.navigator&pli=1) with **5,000+ downloads**. The product website, [joinsafedeal.com](https://www.joinsafedeal.com/), links to the app and the browser extensions; it is not my work.

## Stack Decisions

Expo and React Native with TypeScript. react-native-webview with injected JavaScript for the shopping browser, Zustand for app state and React Query for analysis requests, so each verdict is cached against the page it belongs to.

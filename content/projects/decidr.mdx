## The Problem

Hard decisions rarely stall for lack of information. They stall because the information never gets laid out as a clear comparison: the trade-offs stay buried in spreadsheets and chat threads. Decidr is a personal project that tests whether an AI tool can make that structuring step easy.

## What I Built

Decidr turns a messy dilemma into a **weighted matrix of options and criteria** with scoring you can follow.

- **Intake.** Paste a dilemma in plain text, or step through a wizard: problem, options, criteria, weights.
- **Extraction.** AI pulls the options and criteria into structured JSON through **OpenRouter**, so the model can be swapped.
- **Scoring.** Ranking runs on the server with risk, confidence and a maturity score. Results show ranked tables, charts, heatmaps and a reasoning trace you can expand.
- **What-if.** Change the weights and the ranking recomputes in the browser without another AI call.
- **Compare and share.** Put two decisions side by side, share a public `/d/[token]` link, or print to PDF.
- **Accounts.** Email sign-in and data on **Supabase**, with the Next.js App Router.

Try it: [decidr-henna.vercel.app](https://decidr-henna.vercel.app/).

## Key Challenges

**Prompts that work across models.** With OpenRouter in front of several providers, the prompts and the JSON parsing can't rely on one model's habits. Extraction has to return the same structure whichever model answers.

**The matrix is the product, not the chat.** Keeping the matrix at the centre meant a clear line between what the AI suggests and the weights the user owns.

## Results

A personal prototype, deployed publicly during development. The decision flow, charts and share links work on the public Vercel deploy.

## Stack Decisions

OpenRouter so the scoring is not tied to one vendor's pricing or availability. Supabase for auth and data without a custom backend, so the time went into the matrix and the scoring rather than infrastructure.

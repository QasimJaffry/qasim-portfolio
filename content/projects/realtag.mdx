## The Problem

Detecting an object in one camera frame is a solved problem. Recognising the **same physical object** again, across frames, angles and lighting, and keeping your own name and notes on it, is harder. It also had to feel like a live camera app rather than a research notebook.

## What I Built

RealTag pairs an **Expo** app using **Vision Camera** with a **FastAPI** server that runs on a computer on the same Wi-Fi:

1. **Detect.** YOLO11 finds objects in JPEG snapshots taken from the live feed every few seconds.
2. **Segment.** SAM2 draws masks automatically, or at the point you tap.
3. **Tag.** Give the selected object a name, notes and a colour. DINOv2 turns its crop into an embedding.
4. **Find it again.** Later frames are matched against saved embeddings by similarity, so the same object keeps its tag.

On the phone, IoU tracking keeps overlays steady between server calls, Skia draws them, and MMKV stores the tags.

- **Full-screen camera** with a continuous detection loop against the local server.
- **Automatic and tap-to-segment masks** from YOLO boxes and SAM2 point prompts.
- **Your own tags**, not a fixed product catalogue: you name what matters in your scene.
- **Re-identification** by DINOv2 embeddings.
- **Steady overlays** so boxes don't flicker between polls.

## Key Challenges

**Three models on a live feed.** Detection, segmentation and embedding are chained, so the heavier SAM2 and DINOv2 stages run on cropped regions rather than full frames.

**A server that keeps up.** The FastAPI server has to stay responsive while a phone streams frames to it. Earlier on-device experiments led to this split between phone and server.

## Results

Runs end to end: live detection and segmentation on frames from the phone, custom tags, and re-identification of tagged objects in later frames.

## Stack Decisions

YOLO11, SAM2 and DINOv2 each handle one part: fast boxes, precise outlines and stable embeddings. No single model does all three well. FastAPI keeps PyTorch serving light on a local network, and Vision Camera with Skia keeps the app a full-screen camera.

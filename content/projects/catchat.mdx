## The Problem

Most AI chat products are a text box around a generic model. There are no characters, no sense of who you are talking to, and little reason to open them again.

[CatChat](https://catchatapp-6f11c.web.app/) needed a cast of cat companions to browse, each with a personality and a scenario, and chats that stay in character.

## What I Built

I built the CatChat web app at Star Computer Labs: the Next.js front end, Firebase Auth and Firestore, and the Cloud Functions API that generates cats and runs the chat. A teammate also worked on the functions.

- **Companion grid.** Browse AI-generated cats with a name, personality, scenario and portrait.
- **Character card.** Open a cat to read its personality and scenario, then sign in to start chatting.
- **Chat.** A two-pane layout on desktop (chat list and thread) and a single thread on phones, with a typing indicator and quick-start prompts.
- **Account.** Email and password sign-in, a profile and a feedback form.
- **Installable PWA.** A static export on Firebase Hosting with a service worker.
- **Character pipeline.** A language model writes each cat's profile and Stability AI draws its portrait. The files go to cloud storage and Firestore.
- **Internal tools.** A stats page to set up cats, regenerate images and check usage. It is not part of the public app.

## Key Challenges

**Staying in character.** The system prompt carries each cat's name, personality, description and scenario, and the recent thread is sent as context. Replies have to sound like a cat (short lines, the odd *action*), stay family-safe and never slip into "as an AI" phrasing.

**A static front end with a live back end.** The Next.js app exports to static files on Firebase Hosting, and chat and cat generation run in Cloud Functions, so the PWA itself never needs a server.

**A catalogue worth browsing.** Blank or hand-made avatars would not sell the idea, so generating and regenerating cats had to produce a usable set of characters.

## Results

Live at [catchatapp-6f11c.web.app](https://catchatapp-6f11c.web.app/): pick a companion, sign in and chat in character on desktop or phone.

## Stack Decisions

Next.js App Router with static export for the PWA. Firebase Auth and Firestore for users, cats and threads. Express on Cloud Functions for chat and cat generation, with Anthropic Claude for chat and Stability AI for portraits, so model keys never reach the browser.
